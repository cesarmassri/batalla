# 🌊 Batalla Naval Vibes ⚔️

**Batalla Naval para jugar con amigos** — versión web simple y divertida.

Juega desde el celular o la computadora sin instalar nada. Perfecto para pasar el rato con amigos, en pareja o en familia.

---

## 🎮 Cómo jugar

1. **Cada jugador** abre el mismo link en su celular o compu.
2. En la fase de colocación:
   - Toca las casillas en **"Mi Tablero"** para colocar tus barcos (puedes poner y quitar libremente).
3. Cuando ambos estén listos → pulsa **"¡Empezar Partida!"**
4. A jugar por turnos (hablando o por chat):
   - Dices una coordenada (ej: "D7")
   - En el **Tablero Enemigo** registras el resultado haciendo clic:
     - 1 clic = 💧 Agua
     - 2 clics = 🔥 Tocado
     - 3 clics = 💥 Hundido
     - 4 clics = vuelve a vacío
   - Cuando el rival te dispara, toca la casilla en **tu tablero**.

### Flota enemiga
Debajo de tu tablero puedes ir tachando los barcos del rival cuando los hundas (solo toca el barco para marcar/desmarcar).

---

## ✨ Características

- Totalmente offline (no necesita servidor)
- Funciona excelente en celular y computadora
- Colocación libre de barcos (sin reglas estrictas)
- Diseño limpio y responsive
- Sin alertas molestas durante la partida
- Modo de juego por voz o chat (ideal para amigos)

---

## 🚀 Cómo usar en GitHub Pages

1. Crea un nuevo repositorio en GitHub
2. Sube el archivo `index.html`
3. Ve a **Settings → Pages**
4. En "Source" selecciona **Deploy from a branch** → `main` → **Save**
5. Espera 1 minuto y entra al link que te da GitHub

¡Listo! Ya tienes tu Batalla Naval online.

---

## 📱 Recomendaciones

- Abrir en **modo pantalla completa** en el celular (menú del navegador → "Agregar a pantalla de inicio")
- Usar modo oscuro del teléfono para mejor experiencia
- Jugar con volumen bajo (por los posibles gritos de "¡Hundido!")

---

## 🛠 Tecnologías usadas

- HTML5 + CSS3 + Vanilla JavaScript
- Tailwind CSS (vía CDN)
- 100% frontend (sin backend)
